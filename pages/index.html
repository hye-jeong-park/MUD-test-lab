Malicious-URL Detection Test Pages

Each page below contains inert / simulated triggers for one malicious-URL category. Submit them to the MUD analyzer and compare the verdict against the expected detection.

MUD detection test only — no real malicious behavior. No real malware, mining, PII theft, external exfiltration, or C2. All inputs go to a local mock endpoint or the console only.

    Expected: PII harvest / credential harvest

    Expected: suspicious JS / pattern / ML

  • TC-05 · obfuscated-js.html

  • TC-06 · exfiltration-like.html

  • TC-07 · malicious-redirect.html
