Browser-Fingerprinting Detection Sample

This page is structured to look like a stealth device-fingerprinting / tracking script: it touches the property surface fingerprinters use (userAgent, platform, languages, screen size, timezone, canvas, WebGL). It reads only coarse, non-PII signals.

MUD detection test only — collects NO personal data. It reads benign browser properties, logs them to the console, and beacons only the signal NAMES (not values) to the LOCAL mock endpoint. No external host is contacted; nothing is stored.
